Неофіційний повний переклад гри [Sovereign Tower](https://store.steampowered.com/app/4113940/) українською: інтерфейс і весь сюжет.

Українська **додається** окремим пунктом у налаштуваннях мови. Інші мови лишаються на місці.

## Встановлення

1. Покладіть `uk_patch.exe` у папку з грою, поруч із `sovereign_tower.exe`
2. Запустіть (знадобляться права адміністратора — гра в `Program Files`)
3. Виберіть українську в налаштуваннях гри

Відкат: `uk_patch.exe -uninstall` — повертає файл гри побайтово в початковий стан.

| Ключ | Дія |
|---|---|
| `-check` | перевірити сумісність із вашою версією гри, нічого не змінюючи |
| `-uninstall` | відкотити локалізацію |
| `-pck ШЛЯХ` | вказати `sovereign_tower.pck` вручну |
| `-export` | витягти файли, які замінює локалізація (для перезбірки під нову версію) |
| `-force` | встановити попри розбіжність версій (не рекомендується) |

## Як це працює

Локалізація — 85 файлів загальним обсягом 7 МБ: файли перекладу інтерфейсу, сюжетний ресурс Ink, шрифтові ресурси, скрипт контролера сюжету і список мов.

Патчер дописує ці дані в кінець `sovereign_tower.pck` і перебудовує внутрішній каталог архіву. Оригінальні блоки даних не переписуються — тому відкат точний і не потребує перезавантаження гри через Steam.

Перед записом звіряються контрольні суми кожного файлу, який замінюється. Якщо гра оновилася і ці файли змінилися, встановлення зупиняється з поясненням, щоб локалізація не відкотила частину гри до старішої версії.

## Чому .exe без підпису

Цифровий підпис коштує грошей, тому Windows SmartScreen покаже попередження про невідомого видавця. Увесь код патчера лежить тут, у `patcher/` — один файл, близько 500 рядків. Можна прочитати або зібрати самостійно:

```
cd patcher
GOOS=windows GOARCH=amd64 go build -trimpath -ldflags="-s -w" -o uk_patch.exe .
```

Дані локалізації вбудовуються в бінарник через `//go:embed` і в репозиторії не лежать — вони в зібраному файлі з релізу.

## Після оновлень гри

Steam під час оновлення перезаписує `sovereign_tower.pck`, і локалізація зникає. Якщо вийшла нова версія гри, запустіть `uk_patch.exe -check` — програма скаже, чи сумісна поточна збірка.
